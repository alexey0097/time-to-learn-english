# Metro CSS

Дизайн-система сайта Time to Learn English: один CSS-файл, один необязательный JS-файл и два шрифта. Сборка и зависимости не нужны.

## Подключение

Скопируйте папку `metro` в корень сайта и добавьте в `<head>` каждой страницы:

```html
<link rel="stylesheet" href="metro/metro.css">
<script src="metro/metro.js"></script>
```

JS подключается без `defer`, чтобы объект `Metro` был доступен вашим скриптам внизу страницы.

## Что внутри

| Файл | Что это |
|---|---|
| `metro.css` | Токены, базовые стили, раскладка и все компоненты |
| `metro.js` | Помощники: «сегодня», «Read more», копирование, сворачивание фильтров, переключение темы |
| `fonts/` | Unbounded и Golos Text (латиница и кириллица) с лицензиями OFL |
| `docs.html` | Справочник: каждый компонент вживую и его разметка |

Откройте `docs.html` в браузере — там всё, что умеет фреймворк.

## Как поменять цвета

Все цвета заданы переменными в начале `metro.css`. У каждой есть светлое и тёмное значение:

```css
:root {
  --line: light-dark(#00712b, #4cc764);   /* главная линия: ссылки, кнопки, акценты */
  --alt:  light-dark(#0063ad, #4aa8ff);   /* вторая линия: онлайн */
}
```

Можно не править `metro.css`, а переопределить переменные в своём файле, подключённом после него.

## Палитра линий метро

Кроме основного зелёного и синего (онлайн) есть ещё 13 цветов — по одному на каждую линию московского метро:

| Класс | Линия | | Класс | Линия |
|---|---|---|---|---|
| `.line-red` | 1 Сокольническая | | `.line-yellow` | 8 Калининская |
| `.line-green` | 2 Замоскворецкая | | `.line-grey` | 9 Серпуховско-Тимирязевская |
| `.line-blue` | 3 Арбатско-Покровская | | `.line-lime` | 10 Люблинско-Дмитровская |
| `.line-sky` | 4 Филёвская | | `.line-teal` | 11 Большая кольцевая |
| `.line-brown` | 5 Кольцевая | | `.line-lavender` | 12 Бутовская |
| `.line-orange` | 6 Калужско-Рижская | | `.line-pink` | 15 Некрасовская |
| `.line-violet` | 7 Таганско-Краснопресненская | | | |

У каждого цвета три переменные:

- `--orange` — для текста, читается на фоне в обеих темах (контраст не ниже 4.5:1);
- `--orange-fill` — «родной» цвет линии для линий, станций, кнопок и значков;
- `--orange-on` — цвет текста поверх заливки.

Класс `.line-*` перекрашивает всё внутри элемента: метку, кнопку, расписание, клуб, а на `<html>` — весь сайт.

```html
<b class="tag line-red">Sold out</b>
<a class="btn btn--primary line-violet" href="#">Join</a>
<ul class="route line-orange">…</ul>
<span class="mark line-red">1</span>            значок линии, как на схеме метро
<div class="notice notice--warning"><strong>Moved.</strong> The meeting is on Saturday.</div>
```

Для сообщений есть смысловые цвета: `--success` (зелёный), `--warning` (оранжевый), `--danger` (красный), `--info` (синий) и блок `.notice` с вариантами `--success`, `--warning`, `--danger`, `--info`.

## Контраст (WCAG 2.2, порог 4.5:1)

Каждый текстовый цвет проходит 4.5:1 в обеих темах: на `--paper` и `--surface`, внутри меток `.tag` (подложка из 14 % цвета), в `.notice` и в отмеченных чипах. Текст на кнопках — тоже (`--on-line`, `--on-alt`, `--*-on` на `--*-fill`).
Меняя цвет, проверьте его и на подложке метки: она темнее фона страницы, и именно там запас меньше всего.

## Цвета языков (страница преподавателей)

| Язык | Класс | Почему |
|---|---|---|
| Арабский | `.line-green` | Панарабские цвета, положительный смысл в исламской культуре |
| Китайский | `.line-red` | Цвет удачи и праздника; белый не используем — в Китае это цвет траура |
| Английский | `.line-blue` | Общий цвет флагов Великобритании, США, Австралии |
| Русский | `.line-sky` | Цвет российского флага; красный не берём, чтобы не вызывать советских ассоциаций |
| Испанский | `.line-yellow` | Золотой цвет флага Испании |
| Немецкий | `.line-grey` | Ближе всего к чёрному цвету флага; коричневый исключён — в Германии он связан с нацизмом |
| Французский | `.line-violet` | Нейтральный цвет: яркие цвета флага уже заняты |
| Португальский | `.line-lime` | Между зелёным и жёлтым — главными цветами флага Бразилии; отличается от арабского |
| Остальные | `.tag--plain`, `.chip--plain` | Без цвета, чтобы не придумывать натянутых ассоциаций |

Цвет всегда дублируется названием языка. Таблица задаётся в `teachers.html` объектом `LANG_COLOR`.

Карточка преподавателя целиком (кнопки, «Read more», ссылки) берёт цвет первого языка из его списка, у которого есть цвет. Если цветного языка нет, карточка нейтральная: класс `.is-neutral` даёт тёмные кнопки и серые ссылки.

## Цвета типов клубов (страница клубов и страницы клубов)

| Тип | Класс | Почему |
|---|---|---|
| Group Meetings, Speed Meetings | без класса, основной зелёный | Живое общение в городе — самые частые форматы; базовый цвет держит страницу спокойной |
| Online | `.entry--alt`, `.is-alt` | Синий уже означает онлайн на главной |
| Board Games | `.line-yellow` | Игра, фишки, кубики |
| Stand-up | `.line-violet` | Сцена и вечер; стендап был фиолетовым и в старом дизайне |

Таблица задаётся объектом `TYPE_COLOR` в `clubs.html` и при сборке страниц клубов.
На главной в расписании цвета типов не используются, чтобы линия не превращалась в пёстрый шум.

## Компоненты

- **Раскладка:** `.wrap`, `.layout` (`__main`, `__aside`, `__top`), `.showcase`, `.grid`, `.cluster`, `.stack`
- **Шапка и подвал:** `.topbar`, `.brand`, `.footer`
- **Начало страницы:** `.intro`, `.lede`
- **Расписание-линия:** `.day`, `.route`, `.route--alt`, `.route-label`, `.legend`
- **Неделя станциями:** `.linemap` (большая), `.week` (маленькая)
- **Списки клубов и людей:** `.entries`, `.entry`, `.entry__media`, `.entry__avatar`, `.entry--alt`, `.count`
- **Блоки:** `.feature`, `.card`, `.card--media`, `.panel`, `.panel--quiet`, `.cover` (остальные ссылки внутри такой карточки остаются кликабельными)
- **Мелочи:** `.tag` (`--alt`, `--gold`), `.btn` (`--primary`, `--alt`), `.link-btn`, `.more`, `.mark` (значок линии), `.notice` (сообщение)
- **Фильтры:** `.filters`, `.chips`, `.chip`, `.chip--alt`
- **Прочее:** `.prose` (текст статьи), `.fold` (аккордеон), `.empty`, `[data-clamp]`

## metro.js

Всё включается атрибутами:

```
data-date="2026-10-04"        отмечает сегодняшнюю станцию или день (по Москве)
data-clamp / data-clamp="3"   сворачивает длинный текст и добавляет «Read more»
data-copy="значение"          копирует значение и пишет «Copied»
data-collapse-below="60rem"   <details> закрыт на экранах уже этой ширины
data-theme-toggle             кнопка переключения светлой / тёмной темы, выбор запоминается
```

Если контент рисуется из JS (как списки клубов и преподавателей), после отрисовки вызовите `Metro.init(контейнер)`.
