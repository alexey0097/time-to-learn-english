Metro CSS

The design system of Time to Learn English. One CSS file, one optional JS file, two fonts. No build step and no dependencies.

Getting started

Copy the metro folder into your project and add two lines to every page. Fonts live in metro/fonts and load from there.

<link rel="stylesheet" href="metro/metro.css">
<script src="metro/metro.js"></script>

Colours

Everything is coloured by tokens on :root. Each token has a value for the light theme and one for the dark theme; the swatches show both. Text colours are checked for at least 4.5:1 contrast on the page in either theme.

Layout

.wrap centres the content. .layout is a main column with a sidebar. Put filters in .layout__top: on phones they go above the list, on desktop at the top of the sidebar. .grid, .cluster and .stack are small helpers.

<div class="layout wrap">
  <details class="layout__top filters panel" open data-collapse-below="60rem">…</details>
  <div class="layout__main">…list…</div>
  <aside class="layout__aside">…panels…</aside>
</div>

<div class="grid" style="--min: 14rem">…cards…</div>

metro.js

Optional. Load it in <head> without defer, so Metro is ready for your own scripts. Everything is switched on by attributes. For content you render later from JS, call Metro.init(container) after rendering.

data-date="2026-10-04"        marks today's station or day (Moscow time)
data-clamp / data-clamp="3"   folds long text and adds "Read more"
data-copy="value"             copies the value and shows "Copied"
data-collapse-below="60rem"   <details> starts closed below this width
data-theme-toggle             button that switches light / dark and remembers it

Metro.init(element)           run the helpers inside freshly rendered content
Metro.copyText("text")        copy any text, returns a Promise
Metro.today()                 today's date in Moscow as "YYYY-MM-DD"
